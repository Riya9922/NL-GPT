# 📖 How to Use the Evaluation Tool

## Understanding What This Tool Does

This is an **AI Output Evaluation Tool**, not an AI chatbot. It doesn't generate answers from scratch - it **evaluates AI responses you provide**.

---

## 🎯 Correct Workflow

### Step 1: Get an AI Response First

You need to obtain an AI response from somewhere else first:
- ChatGPT
- Claude
- Gemini
- Your own AI system
- Any LLM output

**Example:**
- **Your question:** "Tell me about flats in Mumbai"
- **Ask ChatGPT/Claude/etc.** and get their response
- **Copy that response**

### Step 2: Use This Tool to Evaluate

**In the evaluation tool:**

1. **"Your question" field:**
   ```
   Tell me about flats in Mumbai
   ```

2. **"AI response" field:**
   ```
   [Paste the response you got from ChatGPT/Claude/etc.]
   ```

3. **Select criteria** (all are selected by default)
   - ☑️ Claim Verification
   - ☑️ Source Transparency
   - ☑️ Logic & Reasoning
   - ☑️ Missing Factors
   - ☑️ Improve Answer Quality

4. **Click "Evaluate"**

5. **Wait 5-10 seconds**

---

## 📊 What You'll Get

### Evaluation Results:

1. **Claim Verification**
   - Which claims are factual vs opinion
   - Which claims are supported by sources
   - Which claims need verification

2. **Source Transparency**
   - Where the AI got its information
   - Which sources are cited
   - Which sources are missing

3. **Logic & Reasoning**
   - Is the reasoning sound?
   - Are there logical gaps?
   - Are alternative perspectives considered?

4. **Missing Factors**
   - What did the AI miss?
   - What additional information would help?

5. **Improved Answer** (if "Improve Answer Quality" is selected)
   - A regenerated, better version of the AI response
   - Based on evaluation findings
   - With better sources and reasoning

---

## 🔄 Example Use Case

### Scenario: You want to evaluate ChatGPT's response about "flats"

**Step 1:** Go to ChatGPT
- Ask: "What are the best areas to buy flats in Mumbai?"
- Copy the response

**Step 2:** Come back to this evaluation tool
- Paste your question: "What are the best areas to buy flats in Mumbai?"
- Paste ChatGPT's response in the "AI response" field
- Click "Evaluate"

**Step 3:** Review the evaluation
- See which claims are verified
- See what sources are missing
- Get an improved answer

## ❌ Common Misunderstanding

**WRONG:** 
- Enter "flats" as question
- Leave "AI response" empty
- Expect the tool to generate an answer

**CORRECT:**
- Enter "flats" as question
- **Paste an AI response about flats** (from ChatGPT, Claude, etc.)
- The tool evaluates that response and can generate an improved version

---

## 🎯 When to Use This Tool

### Use it when:
- ✅ You have an AI response and want to check its quality
- ✅ You want to verify claims in an AI response
- ✅ You want to improve an AI response
- ✅ You're testing your own AI system's outputs
- ✅ You're comparing different AI responses to the same question

### Don't use it when:
- ❌ You want to chat with an AI
- ❌ You want to generate an AI response from scratch
- ❌ You don't have an AI response to evaluate

## 🔧 What About the "Mock Data" Issue?

If you see generic responses like:
```
"Users prefer convenience. Price sensitivity is secondary..."
```

This means:
- ✅ The system is working correctly
- ❌ But you haven't provided an AI response to evaluate
- ✅ Or you provided a very short response

**Solution:**
- Provide a **real AI response** (from ChatGPT, Claude, etc.)
- Make it at least 2-3 sentences long
- The system will analyze THAT response, not show mock data

## 💡 Pro Tips

1. **Always provide context**
   - User query: Be specific ("flats in Mumbai under 1 crore" vs just "flats")
   - AI response: Paste the full response, not just a sentence

2. **Use real AI responses**
   - The tool works best with actual ChatGPT/Claude/Gemini outputs
   - Not with placeholder text

3. **Select relevant criteria**
   - For factual responses: Enable "Claim Verification"
   - For opinion pieces: Focus on "Logic & Reasoning"
   - For all: Enable "Improve Answer Quality"

4. **Check the improved answer**
   - After evaluation, scroll down to "Improved Answer"
   - This is the regenerated, better version
   - Based on all the evaluation findings
